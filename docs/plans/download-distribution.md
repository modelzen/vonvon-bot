# 下载分发与 Linux 双源

日期：2026-11-04。owner 已授权实施国内 COS + 腾讯 CDN 小流量包、海外仅 Linux 的 R2 镜像，并要求自测后交其在真实环境验收。Windows 差分兼容由独立会话处理。

## 做什么与范围

- Mac、Windows 下载路径和签名清单保持不变，国内下载域名接腾讯境内 CDN，COS 继续作源站。
- Linux 安装引导、清单检查和更新可并行使用国内入口及受控 R2 镜像；不根据地理 IP 猜测网络。
- 首次两个来源同时开始小请求，均可用时优先国内，镜像先完成时给国内最多 300ms 的优先窗口。下载有进展就允许慢速继续；连接或持续无进展失败后尝试备用源。
- 只复制 Linux 两架构包和必要脚本、清单到海外。签名公钥、规范 URL、版本与 SHA-512 仍严格校验。
- 本片不改变产品版本、不重打已发布的桌面安装包、不代替 owner 的最终版本发布验收。

## 现有代码与改法

- `scripts/install.sh` 目前只有固定国内入口且 curl 无连接/无进展超时。保持 BASE_URL 的规范 URL 校验，另列可信传输源，添加并行签名清单选择和有限次安全重下。
- 外层安装命令本身也必须能并行获取完整安装脚本；单一 URL 下载 bootstrap 无法修复最初的不可达问题。提供可复制并经测试的 shell 引导内容，完整收到脚本后才执行。
- `packages/daemon/src/service/standalone-manifest.ts` 的配置增加可选镜像表，保留旧配置兼容；新 API 返回已验证清单和选择的传输源。签名内规范 URL 不随镜像变化。
- `standalone-update.ts` 使用选择的来源与同一配置快照下载，保留安装锁、回退状态、大小/哈希校验；用连接/无进展期限替代健康慢速下载的固定总期限。首版备用源安全重下，暂不承诺跨源断点续传。
- 发布工具支持显式腾讯 CDN mutable bypass 策略，验证实际固定地址上的字节及缓存响应，回执如实记录 CDN。版本化大文件随源站 immutable 长缓存；可变清单和脚本不缓存，错误响应不负缓存。
- R2 镜像需有可重复执行的 Linux 白名单发布/验证入口，原样复制已签名清单，不重签或擅自改 stable 指向；生产入口与凭据在外部配置中明确。

## 风险与拆分

主要风险是并发清理、错误路径、签名信任边界和缓存旧清单。按安装引导、daemon 更新、发布/CDN 三块并行实现和独立审查；云端与发布集成由主会话负责。不扩展 Windows 差分或 Mac 更新算法。代码按依赖拆为三个审查单元，每个 PR 不含 lockfile 和生成文件的改动不超过 1500 行：CDN/R2 工具、Linux 安装与升级、统一发布交接。后两片依赖前一片，最终按顺序进入 dev。
