# 采用 Mind Elixir 并稳定导图画布

owner 反馈自写导图不流畅，允许引入现成库；延续图内编辑、固定节点灰底及不出现图外编辑框的要求。

- 固定 Mind Elixir 5.15.1，按需加载；不使用预发布或额外插件。
- 图库负责树布局、连线、空白拖动和触控板/快捷键缩放；React portal 保留现有节点编辑、菜单与服务器保存流程。
- 图库直接编辑、删除、重排、撤销关闭，防止绕过节点权限和服务端 revision。
- 节点 ID 和折叠状态变化才调整图库结构，保留可复用 DOM；一个 ResizeObserver 合并至每帧一次连线更新。
- 固定画布高度，结构变化保持用户当前节点位置；新增编辑节点进入可见范围。
- 全量语义比较过滤未变的轮询结果；分类一次分组，归档历史不重复扫描。

验收包括大图闲置计数、相机拖动/缩放、展开收拢锚点、节点 DOM 和中文草稿保存、固定节点保护、图内新增与删除。现有 8 秒角色与记忆刷新均保留。
