# 社区配方第一片：从作者草稿到另一账号领取

以 [PRD](../design/accounts-recipes/prd.md) 为准。分支从 dev 6079afd1 建立，带入对审文档。本片先交付可以独立验收的数据与网页，不向稳定客户端接入半成品。

- **目标：** 作者保存一份文字草稿，在完整预览后确认发布；社区读公开介绍。其他账号能获取直接版本、用一次性码领取受限版本并在账号库再打开；在已有作品上发布新版时，旧链接仍指原版。首片可移植配置只支持角色说明；完整群设置、Logo、文件、飞书和群内安装在后续片实现，不以手工录入冒充真实群导出。
- **服务：** Supabase 托管身份、Postgres，完整发布包后续放私有 Storage。首片限长文字以私有行保存，读取和写入均经受限角色/数据库函数。单台现有腾讯云机器可在 Nginx 后运行 Node 服务。浏览器使用同源会话，不接收数据库密码。测试域名、数据库、凭据与旧账号页和官网统计完全隔离。
- **边界：** 同键重试不能再扣码；过期修订不能覆盖或发布；草稿和受限正文不能混入匿名目录；不能跨账号读草稿、管理版本或伪造主体。默认对历史版本与已获权益保持不可变。已部署 Supabase OAuth scope、飞书身份绑定和设备隔离仍是上线条件。
- **本地验收：** 用全新临时 Postgres、独立无特权登录、回环签名测试 issuer 运行真实 SQL 和 HTTP；以作者和两位领取人走发布、重复确认、并发兑换、查看已获取及旧链接。另测网页会话、渲染和超限输入。正式三种 OAuth 的授权页与回程另在 staging 复验。
- **交付与发布：** 不修改官网原 vhost、不部署到用户旧项目；只在本片检查通过之后才在独立 staging 联调。完整桌面入群及实际飞书未联通时，网页不得显示“已安装”“已通知 Bot”。公开生产部署、stable 与桌面发布均不同于提交首片。
