# 银灰桌面标题栏

## 1. 做什么

owner 2026-10-25 比较标题栏预览后选择银灰色：第一行保留原生窗口按钮；第二行保留应用标识、居中的“概览 / Bot / 群组”、搜索和设置。

## 2. 范围

只改桌面窗口外框和必要的布局留白。网页端布局、导航行为、后台服务与数据不变；不扩展 Windows 的安装、后台服务或发布支持。

## 3. 现在的代码

`packages/desktop/src/main.ts` 使用系统默认标题栏，深色 macOS 外观会在浅色应用上方显示深色横条。`packages/ui/src/LocalShell.tsx` 和 `today.css` 已提供居中的第二行导航。

## 4. 怎么改

- Electron 使用隐藏标题栏，保留 macOS 原生红黄绿；其他平台使用 Electron 原生窗口按钮覆盖层。
- preload 仅在桌面页面标记 `data-desktop-chrome="silver"`；页面预留 34px 银灰拖动区域，颜色为 `#e7e8ec`，匹配现有浅色应用。
- 原生全屏进入、退出、页面加载时，通过仅主进程到 preload 的布尔通知同步留白；全屏收起第一行。
- 第二行不改。对话框避开原生按钮区域，按钮与导航保持可点击。

## 5. 测试

扩展现有桌面生命周期用例，覆盖全屏进入、退出、重新加载以及不向其他文档发送窗口状态。保留 sandbox、contextIsolation 和现有 IPC 文档授权检查。

## 6. Codex 自测

在 Mac 的独立工作区构建，使用独立 HOME、VONVON_HOME 和 Electron userData。只放一个停用的本地验收 Bot，不注册真实飞书 Bot、不发送消息。使用 verify doctor 核对独立 daemon 与 UI，再用 Computer Use 检查原生窗口、标题栏拖动、第二行导航和全屏。

## 7. 文档

在产品定义与 v1 计划记录 owner 选择的外观。设计选择不代替准确提交上的实际窗口验收，未经实际验收不标记 owner 验收通过。

## 8. 验收要点

- 银灰第一行约 34px，原生窗口按钮可用，空白区域可拖动窗口。
- 概览 / Bot / 群组仍在第二行居中，搜索、设置可点击。
- 进入及退出全屏后布局正确；网页没有额外标题栏。
- 无真实 id、密钥、本机路径进入 diff；不替换 owner 的已安装应用或数据。

## 9. 风险和行数

原生窗口布局与全屏通知约百行。需要真实 macOS 验证；Windows 只做窗口样式配置，未在 Windows 真机验收。
