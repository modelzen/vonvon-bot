# 配方服务的后台固定地址

## 做什么

后台随桌面启动、作为登录项重启或单独运行时，都能使用管理员配置的配方 API 地址。账号令牌仍只由桌面主进程持有。

## 范围

本片提供编译时固定的 HTTPS Origin 与独立 CLI 的显式环境配置读取。安装 RPC 在后台安装切片调用此读取器；本片不改变系统服务定义或安装系统服务。

## 现在的代码

桌面构建已经将账号 API 地址编入主进程。后台由 tsup 独立构建，登录项的环境仅保存数据目录和运行时路径。只依赖 Finder 或父进程的临时环境无法覆盖登录项重新启动。

## 怎么改

后台两个构建入口统一定义 `__VONVON_ACCOUNT_API_ORIGIN__`。读取器优先使用已编入值；未编入时才读取独立服务的 `VONVON_ACCOUNT_API_ORIGIN`。只接受完整 HTTPS Origin，可带末尾斜杠，拒绝凭据、路径、查询、片段和 HTTP。无效编入值不会退回到环境中的另一目的地。后台安装模块保持自己的短效票据校验、禁重定向和显式 loopback 测试选项。

## 测试

验证登录项环境与编入地址不一致时仍使用编入地址；独立运行的显式地址有效；无效编入值和非安全目的地不能退回到环境。验证构建产物实际包含配置，未配置构建不引入生产默认地址。

## Codex 自测

Mac 隔离 worktree 执行定向单测、后台类型检查和构建。没有飞书操作，不使用真实 Bot 或群。实际安装与登录项验收由整批独立环境验收完成。

## 文档

遵循账号与配方设计的固定 HTTPS 服务拓扑。最终部署配置在仓库外保存，最终验收记录确认具体环境；不在公共代码中嵌入测试项目凭据。

## 验收要点

- 系统服务重启不依赖桌面当前 shell。
- 编入地址不会被父进程环境替换。
- 配置不包含账号令牌或秘密。
- diff 不包含真实 ID、密钥和本机路径。

## 风险和行数

约 70 行，涉及公共后台构建，需要独立审查及最终批次三平台检查。未配置的后台保留配方云操作不可用状态，不猜测目的地。
