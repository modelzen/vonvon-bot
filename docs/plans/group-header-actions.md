# 群设置常用入口

## 做什么

owner 已在本地认可预览：群设置的“对话记录”“使用说明”直接显示在标题栏右侧，群名和外链箭头打开飞书。随后补充窄窗口将这两个动作收入三个点菜单。

## 范围与当前代码

仅调整 `GroupWorkspace.tsx` 的入口与 `group-workspace.css` 的响应式布局。现有对话记录、使用说明弹窗和飞书跳转处理保持原实现；更多菜单保留解除绑定。

## 实现

- 两个按钮沿用 Button 与草稿离开保护，分别打开原 history/help 弹窗。
- 群名按钮沿用 `groupUrl`、`openExternalUrl` 和现有错误反馈，外链箭头常驻，提供可读标签、悬停提示与焦点样式。
- 720px 及以下隐藏常驻按钮，在更多菜单显示同名动作；宽窗口隐藏菜单中的重复入口。CSS 隐藏同时移除不可见控件的键盘焦点与无障碍树。
- 保留 Bot 选择器、设置页签、启用开关、菜单 Escape/点击外部关闭和解绑确认。

## 验证与文档

Mac 上检查标准窗口和 390px 长名称，逐一打开对话记录、使用说明和更多菜单，检查草稿保护与原禁用行为仍通过现有用例。运行 UI 测试、类型检查和构建；更新 product 3.1 与 v1-plan。此项仅移动入口，不新增镜像实现的样式断言测试。

不发送真实飞书消息；飞书跳转在独立内存预览中验证目标调用。打包签名后检查安装内容及真实 App 入口。用户已授权沿用本次会话的 dev 合入、跳过 CI 和更新 App 流程。

## 验收与风险

- 宽窗口两个入口可直接发现，窄窗口在更多菜单可达，群名跳转与群信息相邻。
- 长名称不挤走更多菜单，控件可用键盘操作。
- 不修改后端、绑定数据、命令行为或依赖；diff 不包含真实 id、密钥或本机路径。
- 约 100 行变动，主要风险是窄屏布局与重复入口，使用实际组件交互验证。
