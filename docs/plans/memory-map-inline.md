# 记忆导图内联编辑

## 做什么与范围

按 owner 在 Mac 本地对飞书思维导图和交互预览的反馈，把同样的基本操作接到 App。继续使用现有 HTML/SVG 导图，不增加依赖，不改变“分类 → 记忆”的存储结构。

## 现在的代码与做法

- `MindMap.tsx` 管理选中、悬停收拢、折叠计数和快捷键。展开的选中节点只显示＋；未选中的父节点悬停才显示收拢。单子节点使用水平直线。
- `mind-map.css` 使用 App 的紫色图标 token；根为紫色，固定节点浅色背景，无锁图标；普通记忆无底色。
- `MapInlineEditor.tsx` 使用原生纯文本编辑。再次点击选中节点或直接键入进入编辑；Enter/Esc/失焦提交，输入法组合期间不提交。轮询不覆盖草稿。
- `MemoryMap.tsx` 对接已有新增、修改、分类改名、归档、恢复接口。分类＋和记忆＋都在同分类新增记忆。根＋先输入分类名，再输入第一条记忆；空自定义分类不单独持久化。
- Delete/Backspace 在选中态软删除，编辑态只删文字。固定分类不可删除或改名；自定义分类删除时逐条归档，遇冲突停止并报告进度。详情、历史、移动和恢复保留在右键菜单。
- 修改冻结开始编辑时的 revision；失败保留草稿，旧异步提交不清除新草稿。复用已有角色设定的切换保护。

## 验收要点与风险

- 不新增依赖或迁移，不写 owner 数据；删除仍可恢复。
- 分类批量归档使用现有逐条接口，不是事务；失败时明确报告已完成条数，停止后续删除。
- diff 不含真实 ID、密钥或本机路径。
- 预计改动约 600 行，不含研究记录；App 最终视觉与交互仍交 owner 验收。
