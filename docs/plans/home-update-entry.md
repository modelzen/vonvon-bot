# 全局轻量更新入口

## 1. 做什么

owner 2026-10-29 要求：自动发现新版后，无需进入设置，直接通过首页的小按钮下载；下载完成后再次点击安装并重启。owner 已认可淡蓝小胶囊的预览及位置：搜索、设置之后，工具栏最右侧。本次先提交 dev 供 owner 验收，main 由 owner 统一合入，随下一版本发布。

## 2. 范围

- 全局工具栏在首页、Bot、群组和设置页面保留同一个更新入口。
- 沿用现有自动检查时机、签名校验、下载和安装逻辑，不更改更新源及版本号。
- 不自动下载或重启；不替换本机正式 App，不发布安装包。
- 无更新能力的网页端、未发现新版及更新源不可用时不显示按钮；安装未生效沿用设置中的重试入口。

## 3. 现在的代码

- `packages/ui/src/desktop-update.tsx` 保存自动检查和设置面板的结果。
- `LocalShell.tsx` 承载全局工具栏；`management/UpdatePanel.tsx` 提供手动检查、下载与安装。
- 桌面 shell 的 `installDesktopUpdate` 未下载时下载并返回 `downloaded`，已下载时安装并退出。
- `packages/desktop/src/bridge.ts` 原先只缓存主动广播的结果，手动下载完成后重载窗口可能重放旧的 `available`。

## 4. 怎么改

- 新增 `DesktopUpdateButton`，使用原生工具栏按钮，24px 高、淡蓝色胶囊，图标和短文案为“更新 / 下载中 / 重启更新 / 重启中”。悬停显示版本与完整操作说明，无障碍名称保留完整语义。
- 入口固定在搜索、设置之后；预留 78px 状态空间，状态文字变化不挤动相邻控件。窄窗口保留导航和操作空间。
- Provider 保存共享操作阶段、错误和同步互斥锁，工具栏与设置面板使用同一份；下载中可继续导航，换页不丢失状态，失败后可重试。独立渲染面板时显式使用面板自己的 store。
- 仅安装点击经过 `DraftGuard`，下载不离开页面。互斥锁覆盖异步操作，操作结束后释放；原生安装正常会销毁窗口，若回复后未退出，保留用户重试能力。
- bridge 对手动检查、重试和下载的成功结果统一缓存并广播，窗口重载后得到最新阶段；失败不覆盖最近成功状态，退出后不再发送事件。
- 产品行为更新到 `docs/product.md` 3.1，沿用 3.10 的退出和清理流程。

## 5. 测试

- 新版自动出现、无新版及无 shell 时隐藏、跨页面保留入口（main 无入口）。
- 第一次点击仅下载；下载完成后再次点击先经过草稿保护（main 无工具栏操作）。
- 跨入口及快速重复点击只启动一次操作；失败可重试；操作回复后不永久锁定。
- 自动 `available` → 手动下载 → 窗口重新订阅，必须重放 `downloaded`；检查/重试失败不覆盖缓存（main 必败）。
- 沿用桌面更新器、facade、bridge 和原生生命周期测试，覆盖签名失败、超时和退出清理。

## 6. Codex 的自测

- Mac 上使用隔离 HOME、VONVON_HOME 和 daemon，按 verify 的 doctor 核对构建与运行入口。
- 通过 Codex 自带浏览器验收真实 React 页面；shell 的下载、重启和错误使用明确标注的模拟，不对生产更新源或正式 App 执行升级。
- 验证下载中切页、完成后再次点击、未保存草稿阻止安装、失败重试与窄窗口布局，保留截图。
- 本次本地结果：全仓 typecheck/build 通过；UI 78 文件 832 项通过；桌面 bridge、facade、更新器和原生生命周期 4 文件 184 项通过。浏览器交互确认 24px 高、760px 窗口无横向溢出；下载期间切换设置后状态保留，下载完成与设置面板一致，工具栏相邻控件坐标保持不变，模拟重启后入口消失。Codex 内置浏览器控制连接不可用，本轮补充交互通过 ego-browser 完成；此前外观及位置由 owner 在内置浏览器预览中确认。
- 不涉及飞书消息，不使用任何真实 Bot 或群。实际签名包下载、安装替换和重启仍须后续版本候选验收，网页模拟不能替代。

## 7. 文档

- 修改产品定义 3.1 的全局更新入口；在 v1-plan 记录本次 dev 交付及验收边界。

## 8. 验收要点

- 工具栏最右侧为小胶囊，不遮挡页面、不弹更新对话框。
- 下载、安装各由用户独立点击；草稿保护与原生安装清理均保留。
- 设置与工具栏同步操作，失败可重试，窗口重载不会把已下载状态退回下载入口。
- diff 不含真实 id、密钥或本机路径。
- 仅交付 dev，等待 owner 验收与统一合入 main。
