owner 的原则（`docs/product.md` 第 11 节"智能模式不靠规则，关注度照人来做"）："智能模式下，bot 要不要创建一个新的话题、要不要回答，都是靠智能模式的提示词来判断的。回答内容由 bot 自己的 agent 决定；回答要不要艾特，也是由它自己的提示词决定的。这些都不是靠任何规则设置的。"本片做的正是把智能群里最后几条规则拿掉：三条底线、一人聊捷径、"被 @ 一定回"。程序留下的只有：认出"有人找我"的几种硬信号（决定马上判、不决定回不回），判断的超时，和出错、超时时的兜底（owner 定：真人 @ 我、引用我、一人聊照旧回，免得人白等；没点名的、bot @ 我、叫名字的不回）。不加任何决定回不回、开不开话题、@ 谁的规则。规则模式不动。

## 1. 做什么

用户能看到的变化（`docs/product.md` 3.4"三条底线（规则模式）""智能模式怎么判断"、3.5"主区里被 @ 时回在哪里（智能模式）"）：

- 智能群里，@ 了别人、@所有人、引用别人的消息不再被扔掉：它们和别的没点名消息一样进关注度（s25g），到点由判断看，判断看得到"@ 了 小审""@ 了 所有人""引用 张三：…"这些事实，自己定回不回。话题里也不再看"最后说话的是哪个 bot"。
- 真人 @ 我、引用我的消息、在我的回答下开的话题里直接发的消息：也交给判断，判断说不回就不回，判完拿掉 🤔，消息上什么都不留，原因只记诊断页。判断出错或超时照旧回：主区回在主区，话题回在话题。
- 正文里叫我名字（没 @）：马上单独判一次，判断说回才回；出错或超时不回，诊断页记一条。名字太短或是常见词的不算叫名字，照普通消息攒着。
- 话题里只有一个真人在和我聊：不再跳过判断直接回；先判断，出错或超时才直接回。
- 多 bot 群主区不 @ 的命令（`/help` 这类和 `/goal`）照旧不判断不回。
- 诊断页三条文案改成对真人和 bot 都成立；密钥页、判断模型选择里的"要判断的消息按出错处理（…）"改成"没点名的不回，真人 @ 的照旧回"。

依赖：s27a（#424）、s25f、s25f2、s25g 四片都已合入。4.0 先验。从它们合入后的 `main` 开分支 `codex/s25e-smart-entry`。

产品依据：`docs/product.md` 3.4"三条底线（规则模式）"（末段）、"智能模式怎么判断"第 1 到 3 条和"判断出错或超时""判断不挡别的消息""开在哪条下面"几条、3.5"主区里被 @ 时回在哪里（智能模式）"；参数见 `docs/v1-plan.md` 第 5 节"叫名字算不算有人找""判断的超时"。

### 4.1 新文件 `D/bot/salience.ts`

纯函数加一个带注入的 async 函数，不读时钟、不写日志（日志由调用方按返回值记）、不抛。

```ts
import type { NormalizedMessage } from '@larksuiteoapi/node-sdk';
import { quotedId } from './baselines';
import { extractMessageText } from './context-weave';
import type { RecentLine } from './recent-lines';

/** 智能群里真人的一条消息，程序认得出的"有人找我"（product.md 3.4"关注度和成本"第 1 条）。只决定马上判还是攒着，不决定回不回。 */
export type Salience =
  | { kind: 'at-me' }
  /** quote：回复了我的一条消息；root：在我的消息下开的话题里直接发的（话题第一条是我的） */
  | { kind: 'quote-me'; by: 'quote' | 'root' }
  /** 去掉 <at> 段后正文里有我的完整显示名（nameCalled 回 full） */
  | { kind: 'name' }
  /** partial：正文里有名字的前两个字、没有全名（调用方记日志 name-partial，M5 看多不多） */
  | { kind: 'plain'; partial?: true };

/** 名字是这些词的不算叫名字（v1-plan 第 5 节"叫名字算不算有人找"）。比较时转小写。 */
export const COMMON_NAMES: ReadonlySet<string> = new Set(['bot', 'robot', 'ai', 'assistant', 'helper', 'test', 'dev', 'admin', '助手', '小助手', '机器人', '测试', '客服', '管理员']);

export interface SalienceDeps {
  /** 我的显示名（channel.botIdentity?.name）；没有就不认叫名字 */
  botName: string | undefined;
  /** 环里这条引用的那一行（quotedLine(recent, msg)） */
  quoted(msg: NormalizedMessage): RecentLine | undefined;
  /** 环里没有时查引用的那条是谁发的（fetchMessageMeta，3 秒）；查不到 undefined */
  lookup(messageId: string): Promise<{ from: 'self' | 'bot' | 'user' } | undefined>;
  /** 话题第一条是谁发的：self / other；不知道 undefined。调用方负责缓存和查飞书（4.2） */
  rootFrom(chatId: string, threadId: string, rootId: string): Promise<'self' | 'other' | undefined>;
}

/** 去掉所有 <at> 段的正文：叫名字只看人打的字，不看 @ 出来的名字。raw 没有时用 msg.content。 */
export function bareText(msg: NormalizedMessage): string;

/** 正文里有没有叫我：full 有完整的名字；partial 只有前两个字（非 ASCII 名、长度大于 2 时才有）；none。 */
export function nameCalled(bare: string, botName: string | undefined): 'full' | 'partial' | 'none';

export async function smartSalience(msg: NormalizedMessage, deps: SalienceDeps): Promise<Salience>;
```

`smartSalience` 的顺序（先到先得，硬信号优先级 at-me > quote-me > name）：

1. `msg.mentionedBot` → `{ kind: 'at-me' }`。bot 发的消息到不了这里（s27a 的门在前面），不查 `fromBot`。
2. `const q = quotedId(msg)`（话题里直接发的 `parent_id === root_id`，算没引用，`baselines.ts` 已这样）。`q` 有：`const line = deps.quoted(msg)`；`line` 有：`line.from === 'self'` → `{ kind: 'quote-me', by: 'quote' }`，否则不是引用我、不查（环里的行可信，省一次查）；`line` 没有：`const meta = await deps.lookup(q)`；`meta?.from === 'self'` → `quote-me`；`meta` 是 `undefined`（查不到、超时）或别人的 → 往下走（设计 1.2：查不到就当普通消息攒着，不再记 `lookup-failed` 不回）。
3. 话题里直接发的（`msg.threadId && !q && msg.rootId && msg.rootId !== msg.messageId`）：`const root = await deps.rootFrom(msg.chatId, msg.threadId, msg.rootId)`；`'self'` → `{ kind: 'quote-me', by: 'root' }`；`'other'`、`undefined` → 往下走。话题第一条就是这条自己的（话题群的帖子）不查。
4. `nameCalled(bareText(msg), deps.botName)`：`full` → `{ kind: 'name' }`；`partial` → `{ kind: 'plain', partial: true }`；`none` → `{ kind: 'plain' }`。

- 纯 ASCII（`/^[\x20-\x7e]+$/.test(name)`）：`name.length < 3` → `none`；`new RegExp(`(^|[^A-Za-z0-9_])${escape(name)}(?![A-Za-z0-9_])`, 'i').test(bare)` → `full`，否则 `none`（ASCII 名不认前两个字：那不是"字"）。`escape` 是 `s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`。
