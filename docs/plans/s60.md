# s60：bridge 纯数据转换

## 1. 做什么
为后续导入准备纯转换入口，尚无用户入口。依赖 s59（#463）、s36、s21、s12。

## 2. 范围
显式快照输入，输出 V1 config/project/session/registry 可接受的数据与每 bot 差异。s59 摘要不是数据源。事务、IO、加解密、getter、目录分配、服务、UI 留给 s61–s63。

## 3. 现在的代码
`import/bridge/preflight.ts` 仅检查摘要；`project/registry.ts` 的 stricterTier、noMentionOf 和 `config/execution.ts` 规定旧群生效值。`bot/session-store.ts` 的 adoptAdminSessions 规定 live #admin 改名、#guest 停用。本片不调用有 IO 的 writer。
旧字段依据：公开 bridge 0.6.14（6698118）schema、registry、session-store、outbound-files；task122 原版 writer 的全合成产物只作来源依据，不宣称迁移真人数据。

## 4. 怎么改
`conversion.ts` 用 Zod 校验显式 snapshot，保留 bot/config 和续接字段。拒绝缺失、非法、重复身份、群或会话键；错误仅位置索引/代码，不回显敏感值。只接受 JSON 自有数据描述符，不执行 getter。纯转换不修改输入。
群固定规则 multi/single，cwd 原样，缺省用现有解析器；双档 stricterTier 并逐群记录差异。live #admin 按既有规则改名；#guest、detached #admin 保留；目标键碰撞明确拒绝整次转换，不静默覆盖。个人指令继续 native 继承，不走新 bot 清空路径，CODEX_HOME 不变。评论提示词与文件记录按 bot 返回。
120 秒移除并逐 bot 提示；其他显式值保留，0 即旧版“关”；缺失取 V1 默认。个性、记忆、skill 不新增。

## 5. 测试
全部为新增契约覆盖；main 无纯转换入口，不能冒称旧路径反证。
- 两 bot 的身份、管理员、提示词和已发文件各自保留；实际 V1 类型与解析器验证。
- 群全部字段、multi/single、免@缺省、cwd/blank 原样；9 种双档组合取更严，仅不同档记录差异。
- Codex/Claude id/backend/model 保留；v1 旧 id 字段转换；v3 标题账本规范键用 sessionTitleJobKey 核对，重复宿主/不匹配引用拒绝，进行中 lease/phase/writeAttempted 保留；#admin/#guest/detached 与无后缀冲突不丢记录。
- timeout 120/其他正值/0（关）/缺失，每 bot 差异互不污染；autoCompact 丢弃。
- 深冻结输入、重复转换一致；缺失/非法/重复身份/权限、getter 明确失败且不执行 getter。

## 6. Codex 的自测
交 Mac，仅纯函数及隔离数据检查；不用测试 bot/群，不发飞书消息，不需 VPS、模型、浏览器、原生服务。isAdmin 等复用 helper 的测试可能读取隔离 app-role 文件；不把整套测试宣称无 IO，转换函数本身无 IO。共享重命令待 root grant，之后隔离 HOME/VONVON_HOME 跑 build/typecheck/lint 与定向转换、schema/session/权限测试，记录准确结果。

## 8. 验收要点
所有 bot/群保留；权限不扩大；无敏感值错误输出；会话不覆盖；无 IO/crypto/getter/服务；差异有 bot/群归属；diff 没有真实 id、密钥、本机路径。s61/e08 真服务与 s62 真续接不由本片关闭。
