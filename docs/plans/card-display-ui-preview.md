# 消息卡片编辑界面验收

## 1. 做什么

在现有网页端的「群组 → Bot → 沟通方式」加入统一的消息卡片编辑入口。先验收界面、入口和交互，再实现 daemon 配置、CLI 和私聊工具的统一能力。

## 2. 范围

本次是开发模式下的隔离界面验收。通过 `?preview=card-display` 注入明确标注的示例 client，使用真实 App、GroupWorkspace、Dialog 和公共控件；不连接实际 daemon，不写入实际配置，不执行自定义脚本。

布局采用 iPhone/macOS 小组件编辑的交互：左侧组件池、右侧卡片、悬停隐藏、进入单项设置。位置继续限定在原生卡片允许的固定位置。配置文本留给 CLI 和对话修改，不提供 JSON 编辑页。

## 3. 现有代码

- `GroupDesignSettings.tsx` 的 `presentation` 原有工具调用、模型显示和完成提醒。
- `run-card.ts` 的上下文在顶部，耗时属于过程标题，执行中的底部状态与模型共用信息行，操作按钮另占底部。
- `process-panel.ts` 控制运行时展开和终态折叠。
- `context-gauge.ts` 提供真实占用文本和颜色分档。
- 顶部回复引用属于飞书消息载体，不属于可配置的 Card JSON。

## 4. 怎么改

编辑器采用两栏。左侧直接展示可移动组件的实际渲染结果，例如用量文字、用时、状态和模型，不再给每个样例增加抽象标题；右侧显示真实卡片。已显示的组件带勾，隐藏的组件可以点击添加。卡片不常驻减号或大框，仅悬停组件或键盘聚焦时显示贴合内容的细边框及外侧隐藏按钮，不默认选中组件，点击范围贴合文字或图形；也可直接拖回左侧组件池隐藏。点击组件打开紧凑的圆角设置浮层，原布局保留在背后虚化。详情不显示位置，移动只在画布中进行。拖动时才浮出合法固定位置，不撑大或重排原卡片，平时没有空槽位网格。卡片开放上方信息行、下方信息行及各行左右位置；终止按钮还可使用底部按钮区左右位置；工具与思考固定在过程区，显示开关单独放在左侧，不作为移动组件；耗时默认在过程标题。上下文进度条可放在信息整行或左右半行位置，切换形态时保留原位置，并随所在位置宽度适配。终止按钮作为独立组件，可隐藏、移动，以及在仅图标和图标与文字之间切换；保留原生回调，仅执行中可用。回复正文、引用、异常提示与其他原有操作按钮不作为可移除组件。owner 否决常驻边框和三图标操作框，恢复直接点击设置、拖动内容换位置的悬停交互；卡片下方常驻同色 20px 向上指的线性手指图标与深色文字“点击卡片内容进行设置，拖动组件调整位置”，自动演示状态另起一行，不在卡片内部添加引导浮层、下划线或额外编辑标题。隐藏按钮与组件间使用连续的悬停命中区域，鼠标跨越间隙后仍可点击。

常用属性是显示时机和展示形态，形态选项直接展示结果。文字模板、字号、颜色规则和脚本样例按需展开。上下文颜色按达到某个百分比变黄、变橙、变红设置；出现条件单独选择不限用量，或达到指定用量才显示。所有 UI 操作共同修改一份声明式草稿。脚本只用样例输出演示。

左侧「回复行为」的输出方式固定为「流式输出」「完成后输出」，另有工具调用、思考内容开关；「更多」提供完成后是否收起过程。选择完成后输出时，默认关闭工具、思考、耗时、执行状态和终止按钮；工具与思考开关及仅执行中存在的组件不可添加。预览立即显示完整终态回答，过程面板和终止按钮不出现。切回流式输出恢复切换前各过程组件的显示选择。最终回答内容相同，模型内部事件流不受影响。现行正式协议只有工具显示和模型显示等已有配置，正文显示方式、思考显示和过程收起属于本次界面草稿扩展，后续统一接入服务端与 CLI；不把 UI 草稿声明为正式配置契约。

默认自动轮播处理、工具、输出和完成，后续轮次覆盖高/低上下文用量；不提供阶段、播放、暂停按钮，也不提供示例或上下文用量下拉框。正文有结论、短列表和结果，逐段增长但默认内容控制在一屏内，避免要求用户滚动。鼠标仅在移入卡片本身或键盘在卡片中操作时暂停（右侧空白、Bot 名称及下方提示区域继续播放），进入组件设置、拖动时也暂停；内容跟随滚动同时停止。离开卡片且没有编辑时恢复。上下文移除原有圆点，仅使用文字/图形和原有颜色分档表达占用。

现有工具调用和模型显示值用于初始化。在验收模式中收起旧显示控件，通知行为仍在完成提醒中。生产路径保留原行为。

## 5. 检查

检查 UI 类型与构建、现有群设置/路由回归、从组件池和卡片自身拖放到合法位置、拖回隐藏及重新添加、悬停操作不盖字、浮层完成/Escape 返回原位置与焦点、文字和进度条切换、流式/完成后输出的默认联动、切回恢复与过程收起、各状态默认一屏内展示、悬停/键盘暂停与恢复、快速拖动不换帧、进入设置后的稳定性、工具显示开关、模板编辑、完成后跨 tab 恢复草稿。检查上下文不重复且无圆点、异常提示和其他操作按钮保留，终止按钮六个合法位置均唯一且保留原回调、引用不含编辑元数据。

## 6. 自测

在本任务 worktree 中构建 protocol/client，使用 UI 的 Vite 开发服务打开 `?preview=card-display`。实际网页导航到沟通方式后，通过「消息卡片 → 自定义」打开编辑器。日常回复与工具过程样例由固定源码的真实 `buildRunCard` 生成，并按 owner 提供的截图校准。无飞书写入测试，无实际脚本执行。

## 7. 文档

后续验收确定后，将产品规则、持久化 schema 和 CLI/API 一起设计及实现；不提前把当前 UI 草稿格式声明为正式协议。Skill 只按最终 CLI 的需要调整，不设计自然语言措辞识别。

## 8. 验收要点

- 操作遵循固定槽位；详情只调整显示属性，不重复提供位置选择。
- 工具、模型及新增显示内容集中在同一个编辑器。
- 默认结果遵循真实卡片结构；引用完全不在配置范围。
- 默认只显示组件池、固定内容开关和卡片；点击组件进入紧凑的单项设置浮层，高级功能按需展开。
- 自动演示覆盖多种情况，交互期间保持暂停；一屏呈现，不需要选择示例、阶段和用量档位。
- 原生卡片 JSON 与客户端引用分开；无真实 id、凭据或本机路径进入 diff。
- 明确区分界面验收和功能完成，不向真实服务写设置。

## 9. 风险与行数

仅涉及 UI 编辑器、预览数据和开发入口。主要风险为预览布局误导、显示项重复、草稿丢失和槽位验证不一致；以原生生成数据及上述检查约束。后续接入 CLI/服务端时需另行覆盖权限、冲突、旧配置兼容和脚本运行生命周期。

## 10. 本轮本地验收记录

- 浏览器实测两种输出方式，完成后输出立即展示完整回答，过程开关自动关闭，切回恢复。
- 实测左侧及右侧组件的隐藏按钮，鼠标跨过组件与按钮之间的间隙仍可点击。
- 实测上下文移到底部、终止按钮移到按钮区右侧、拖回组件池隐藏和重新添加。
- 对照提供的飞书卡片和 iPhone 设置截图检查紧凑组件边界、原生颜色、无常驻下划线、设置浮层及背景虚化。使用本地生成的原生 Card JSON 模拟显示，不声明已在真实飞书客户端验收。
- 1000×800 浏览器视口默认组件池及预览均可一屏显示；高级选项展开及添加更多自定义组件可滚动。

- 本轮自动化检查通过：UI typecheck、UI build、群设置/路由 19 项回归、终止按钮模型断言、git diff --check。构建仅有依赖 use client 与包大小提示。21 秒轮播观测覆盖工具、流式与完成，卡片最高 402px，组件池与预览无溢出；另存完成后输出截图和轮播指标。

- 本轮补充：上下文进度条实测可从拖动把手移入右半行，切换百分比及进度条保留原槽位；颜色分档、出现下限与演示阶段分开，组件池样例不被下限规则隐藏。

- 最新上下文验收：设为 80% 起显示时，运行样例 78% 隐藏，完成样例 80% 显示；颜色边界、三种形态一致性、六个信息槽位、草稿 roundtrip 与非法规则拒绝均有断言。浏览器实测使用把手拖到右半行（279px / 卡片 600px），高级颜色与出现规则在 1000×800 视口可见。UI typecheck/build 与 19 项原有设置回归通过。

- 颜色档位可分别启用或关闭；关闭橙色后跳过该档，关闭黄色和橙色后可以只保留红色。阈值递增只约束启用的档位；例如只启用 80% 红色，未启用的橙色保留 85% 也合法。显示条件仍独立设置；“80% 起显示 + 80% 红色”实现此前隐藏、此后只红色。
- 仅在上下文详情中提供详情顶部小滑杆（预览右侧、“完成”左侧），悬停可查看用量百分比，立即更新详情顶部及卡片预览；未达到显示条件时明确提示不显示。预览百分比为临时界面状态，不写入草稿，不计入配置撤销历史；退出详情恢复自动轮播样例。主编辑器仍不增加示例或用量下拉框。

- 最新细节：保留“达到 X%，变为黄色/橙色/红色”句式，每行右侧单独开关；预览用量滑杆置于标题预览和完成按钮之间，使用简单紧凑样式，不另占一行。固定操作提示与自动演示状态分开，不因拖动后的状态文案消失。

## 11. 组件配置复核

- 上下文：保留显示阶段、三种形态、颜色档位开关与百分比、出现用量；详情顶部的小滑杆仅用于预览。
- 耗时：补充“仅完成后”，可避免执行过程中持续显示耗时。上下文、模型和自定义信息也共用全程/执行中/完成后三档。隐藏仍由组件自身的隐藏操作完成，不再在阶段选择里重复。
- 模型：保留显示阶段及高级文字、字号、颜色，默认继续展示真实模型与思考强度。
- 执行状态：固定跟随真实任务，只在执行中出现；撤掉固定文字编辑，避免填写固定文案后掩盖真实状态；字号与颜色放在更多设置中。
- 终止按钮：仅执行中存在，保留图标/图标与文字及按钮文案；无额外阶段、字号和颜色开关。
- 工具、思考：固定在过程区域，以回复行为开关控制；完成后输出时禁用过程项。
- 自定义信息：模板与脚本样例保留在高级设置，仍只用样例，不执行脚本。
- 左下角弯箭头原本是撤销；增加“撤销”文字，没有修改时禁用，预览滑杆不产生撤销记录。同值写入不再产生无效果的撤销步骤。

- 最新浏览器验收：无修改时撤销禁用、同值恢复默认不产生历史、只拖预览滑杆不产生历史、切换样式后撤销可恢复文字；“仅完成后”的耗时在运行中隐藏并可撤销恢复。执行状态详情没有固定文案输入。
- 只启用 80% 红色并设置 80% 起出现：滑杆 79% 隐藏，80% 红色，100% 红色；预览到 100% 后颜色起点仍为 80%。核对详情顶栏顺序为实际预览、小滑杆、完成；三个颜色开关均位于原句式右侧。操作提示和同色手指图标已恢复，未增加常驻组件框。
- 最终 UI typecheck/build、19 项群设置/路由回归、颜色/显示边界及完成阶段模型断言、git diff --check 均通过。真实服务配置、脚本执行及 CLI 接入仍不在本轮验收范围。
