# 记忆页只保留导图

owner 本地验收提出：不要导图之外的编辑框或窗口；加号直接在图中输入。

- 记忆新增、改名、编辑保留原位输入；固定分类不能删除。
- Bot 身份与职责、其他说明、本群角色通过同一个节点编辑器保存。
- 继承内容保持只读，完整文字和来源在选中节点的子节点中展开。
- 详情、历史、撤销、分类迁移、跨项目迁移、可信确认和彻底删除，都使用图内子节点。
- 右键操作、搜索和错误提示在图内展开，不再打开弹窗或侧面详情框。
- 离开页面先自动提交节点；失败保留草稿并停留，错误显示在图内。
- 保留原有 settings/memory revision、权限、长度、来源和归档保护。不增加依赖。

验证：UI typecheck；全 UI 测试；隔离数据下实际点击 Bot/群记忆页，检查角色保存、加号新增、编辑删除文字与选择删除节点、详情与历史均无外部面板。打包后使用隔离数据启动本地 App。
