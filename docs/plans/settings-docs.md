# 设置入口与官网文档同步 · 2026-11-04

## 做什么

按 owner 已确认的本地方案调整设置标题、图标和具体跳转，同时官网文档按实际界面补齐操作说明、截图与文字注释。保留所有现有目的地和功能，产品与官网文档一起发布。

## 范围

设置首页保留“模型与工具”“连接与应用”两块及顺序。标题为 Provider、工具、决策模型、用量、设备连接、飞书连接、Bridge 导入、应用与启动、诊断。保留摘要和完整用量、集中飞书检查、Bridge 回执/恢复、平台差异与更新提示。不修改决策算法、Provider 支持范围或默认配置。

## 现在的代码与修改

- TodayHome/today.css：现有分块和行结构，替换图标色彩、简短标题和准确说明。决策说明覆盖是否回应、回复位置及创建新话题。
- Provider/SettingsPanel：Codex 可执行文件路径从应用设置移入 Codex 高级设置；保留原保存、自动检测恢复、错误、草稿与重启语义。运行后备目录留在应用与启动。
- App、WelcomeSetup、FeishuConnections：Provider 检测进入正确 Provider；Bot 管理、诊断和注册完成进入飞书检查时保留目标 Bot；全局入口仍允许切换 Bot，首次引导保留。
- search：旧标题仍可找到新入口，路径编辑打开对应高级设置，不与运行后备目录混淆。
- 官网独立仓库：17 篇文档、实际截图和 HTML 注释；正文静态可读，同源生成 Markdown 和索引，无额外可见 Agent 入口。

## 测试与自测

针对 Provider 路径保存/搜索、误跳转和目标 Bot 传播进行回归；UI 类型检查、测试和构建。Mac 隔离 HOME/VONVON_HOME 启动真实后台，浏览器检查设置、Provider、飞书连接和诊断；仅使用停用的演示 Bot，不发飞书消息，不操作 owner 服务。官网构建、全站测试、正文/图片/Markdown/站内锚点校验，桌面和窄屏验收。

## 文档与验收

同步 docs/product.md 设置说明和官网操作路径；官网截图以本次构建实拍，示意流程保留标识。检查所有旧入口仍可找到对应功能、错误和恢复操作；diff 不含真实凭据、群 ID 或个人路径。owner 本地方案确认仅作为实现依据；完成后的实际产品与文档一起交付验收。

## 风险

不变更后台配置格式。主要风险是跨页跳转丢失目标、搜索未展开路径字段和平台作用域混淆；用对应回归与隔离 UI 验证覆盖。预计产品改动低于 1,000 行；官网在独立仓库交付。

## 本轮实际验证

- protocol、client、daemon、UI、desktop 构建通过；UI 类型检查通过，108 个测试文件的 1,076 项测试通过。
- 独立检查发现 Codex 路径读取缺超时/重试、加载时搜索锚点缺失，已修复并加回归。
- 真实浏览器发现搜索慢读取时重复设置 details.open 导致 MutationObserver 自循环，已加幂等判断和回归；重新构建后，首次搜索路径可展开高级设置并定位字段。
- 使用停用演示 Bot 的隔离后台核对新设置、Provider/诊断路径；未执行真实飞书发送、注册、分享、任务或桌面外壳验收。
- 官网18篇正文、实际截图与文本注释同批交付，构建和全站检查通过。
