## 怎么改

- NowBotList 通过现有 membership / attention 形成 Bot → 群树。四段横向刻度对应既有关注档位，省略分值和话题细节；Tooltip 展示简短说明。成员状态不可读、停用、断连、预算限制和预算到期均不能表现为正常关注。
- 在 Provider 事件消费及模型判断落点汇总有界内存 diagnostics。并发任务各自拥有 ID；终止只清除对应任务。仅传受控阶段、工具类别和群 ID，不发送正文、原始工具参数或思考内容。token 事件合并更新，退出清理。
- 群动态只收真实成功的模型判断，时间取判断完成时间；显示接话意图和触发事实。列表在悬停、键盘阅读和查看历史时延后刷新；减少动态效果模式禁用移动效果。
- Provider 登录透出安全账户分类；已安装不等于已配置。首页与设置页复用查询、额度及活动统计组件，首页左侧每日活动与累计统计、右侧额度；详情跳转设置用量页。Jev 放在同一切换项，仅展示该来源的每日日期与次数，最多约五行高，更多日期在区域内滚动，无重复标题和汇总说明。隐藏页停止刷新。Codex 日格图区分缺失、零和未来；API 或不支持的 Provider 不显示虚构订阅额度。
