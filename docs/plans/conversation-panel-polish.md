# 对话记录整理

## 做什么与范围

2026-10-26 owner 在 Mac mini 认可「群设置 → 对话记录」交互预览，要求照此实施。沿用本次会话的合入 dev、跳过 CI、更新本机 App 流程。

当前 ConversationPanel 将会话统计、操作、目标输入、搜索、筛选和历史记录放在设置行中；长路径和底层后端名称常驻占用空间。本次只整理此面板及其群设置弹窗，不改变会话请求协议或后台行为。

## 实现

- 当前会话标题、上下文统计及压缩/清空操作集中为摘要卡；上下文窗口已知时展示占用进度，未知时不推算百分比。自主任务目标按需展开。
- 保留运行中任务、停止、结束目标、子任务、提醒，以及各操作原有禁用条件。运行状态采用预览认可的静态标识。
- 历史记录突出标题、时间、Provider 和状态；原始会话 ID、后端、目录与完整时间展开查看。搜索和筛选组成工具栏，窄窗口自动换行。
- 群设置弹窗标题改为「对话记录」，群与 Bot 放在副标题，采用预览认可的宽度与内边距。
- 保留搜索匹配、排序、恢复与飞书打开目标、错误和空状态。展示上下文前核对其 threadId，防止旧会话状态短暂错配。

## 验证与文档

更新已有会话面板回归，保留子任务停止参数和轮询清理覆盖；运行 UI 测试、全工作区类型检查与构建。用内置浏览器核对实际组件与已认可预览一致，覆盖默认、运行、独立话题、长内容、空记录、读取失败及重试；操作使用匿名演示数据。安装后检查签名、产物一致性、App 与 daemon 启动和真实只读界面。
