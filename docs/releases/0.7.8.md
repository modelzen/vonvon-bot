# Vonvon Bot 0.7.8

- Codex 模型列表跟随本机 CLI，保留原生名称、排序及可见性，并支持刷新。
- 会话与群组支持按当前模型实际能力选择响应速度。飞书模型卡片可点击闪电直接轮换可用档位，普通为灰色、Fast 为黄色、Ultrafast 为橙红色。
- 群组新增记忆提示可以定位到对应记忆；记忆图内可直接查看来源、编辑及归档。
- 顶部工具栏可查看更新状态，并与更新设置页共享下载、重试及安装状态。
- 明确退出桌面应用时停止后台与 Bot；关闭窗口仍保留后台运行。
- 修复 Windows Codex 权限能力识别与初始化兼容问题。
- 修复 Codex 检测进程已确认退出后仍拒绝重试的问题；清理状态未确认时仍阻止启动重复检测进程。

macOS Apple 芯片、Intel 与 Windows x64、ARM64 使用同一产品版本。Windows 安装包仍未签名，使用手动更新。
