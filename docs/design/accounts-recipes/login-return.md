# 分享链接登录后继续领取

2026-11-14。owner 在妙搭调研后确定继续原方案：Vonvon 业务账号、Supabase Auth 与自有社区网页，首版不接飞书登录。会员与设备等后续业务继续归属稳定的 Vonvon 账号；本片不新增会员功能。

## 用户看到的流程

分享链接固定到配方及其某次发布版本。未登录可以查看公开配方的完整信息；凭码版本只展示介绍。点击「获取配方」后选择当前环境已启用的登录方式，成功后返回同一版本，接上确认框或分享码输入框。授权登录不领取配方，也不消耗码。普通账号登录返回当前页面，不自动打开领取。

用户可以取消确认。登录取消或失败仍回原版本，允许重新登录。详情暂时读取失败时保留继续领取状态，重试成功后继续。其他页面的登录状态检查不会清除此状态，同一版本的另一个标签也不能抢走它。恢复一次后刷新不重复打开；已取得该版时直接展示已获取。

## 实现边界

OAuth flow 保存白名单内的固定版本路径和领取意图。当前标签通过 sessionStorage 保存本次非敏感随机标记，服务端在同源、有当前会话标记且版本/随机标记均匹配的消费请求中移除一次性意图；查询登录状态不消费。禁用 sessionStorage 时仍可正常登录并回原版本，用户再次点击领取即可。

完整配方分享页复用 App 的配方详情组件、返回和获取按钮。Web 服务读取 v2 的精确版本及其被授权引用的正文、Logo，校验版本归属、字节数和哈希；凭码未领不读取正文。网页只展示介绍及可移植配置，不提供设备控制。旧版文字配方仍可读取。
