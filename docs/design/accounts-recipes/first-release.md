# 首发配方 · Vonvon Bot 使用与排错助手

社区优先发布一份能让用户在自己设备上提问和排错的配方。日常用法直接答，能解决的故障在本地解决。排除配置问题后仍能复现产品异常，才准备一份交给维护者的 issue。维护者从飞书多维表格接收和跟进反馈。[首发配方的原始讨论](https://github.com/modelzen/vonvon-bot/blob/8be1d9128ff44b812ce1e5d159685f7d477b1a5e/docs/handoffs/accounts-recipes-2026-11-13/conversation.md#L48-L50) · [反馈如何跟进](https://github.com/modelzen/vonvon-bot/blob/8be1d9128ff44b812ce1e5d159685f7d477b1a5e/docs/handoffs/accounts-recipes-2026-11-13/conversation.md#L162-L164)

## 用户怎么用

有人问「怎样让 Bot 只在被 @ 时回应」，助手按对方所用版本给出入口和官方文档。有人说「昨天还会回，今天这个群没回了」，助手先问发生时间、其他群是否正常，再引导核对本群的 Bot、沟通方式及「最近没回的消息」。先留下界面给出的原因再考虑重启，因为重启会清空这项记录。能够复现且证据指向产品时，助手把复现步骤、预期和实际结果、版本、系统及必要的脱敏证据整理成一份可以预览的报告。原因仍不明时，报告说明尚待核实的部分。[官网排错指南](https://vonvon.cc/docs/troubleshooting/)

目前的独立网页支持匿名阅读公开配方的介绍、角色和准备说明，登录后可加入账号库并再次打开。用户可以在本机照步骤检查，分享他们选择的简短结果。领取本身不授予读取设备日志或代填反馈的权限。正式上线前，还须以领取者在真实设备上打开的具体版本验收，并按实际可用的能力写介绍。

本机验收首页以「最新配方」显示最近发布的版本。当前尚未接通运营精选与正式作者标识，不根据配方名称认定官方身份。下表的官方版本固定入口是公开上线前的待办，不能把本机合成发布者当成已验证的正式发布账号。

用户核对报告后，打开[官方问题反馈表单](https://my.feishu.cn/share/base/ExampleReference6)。填写者可以匿名提交。问题标题和实际结果必填，版本与系统、复现步骤、预期结果、脱敏补充可留空。填写者可直接将助手整理的整份正文贴进「实际结果」。只有飞书填写页面能确认提交成功，Vonvon 只能确认自己打开了链接或复制了正文。看到飞书成功提示后无需重交。

## 上架前逐项走一遍

| 验收场景 | 执行与判据 |
| --- | --- |
| 官方身份和内容来源 | 管理者核对发布账号与配方、版本的归属，核对所引用官方文档的版本与可访问性。另用普通账号发布同名配方，社区入口仍应指向确认过的官方版本。验证环境的测试作者不能据此获得正式署名。 |
| 用法与答案来源 | 用户询问一个有官方说明的设置。答复给出可执行的步骤和对应文档。再问一个文档未覆盖的问题，助手指出需要补充哪项信息，避免凭空给出功能、按钮或原因。 |
| 本机排错 | 用专用测试群制造一项已知的配置不匹配。在领取者设备上按步骤定位，给出一个改动及复验办法。若版本支持读取本机诊断，先让用户看到读取范围并取得授权，只读此设备和需要的项目。用户不授权时可手工检查。 |
| 用户同意反馈 | 用一个已知产品缺陷准备报告，排除无关的私聊、机器路径、身份标识和密钥。向用户显示提交目的地和完整正文，允许编辑。通过维护者确认、普通用户可访问的官方渠道提交，并在测试接收端核对实际收到的内容。自动代交还须有接收方授权；仅展示报告、复制正文或打开表单的阶段，只提示相应动作。 |
| 用户不提交或提交失败 | 用户在预览后取消，接收端应无新记录。将测试接收端设为不可用，保留用户核对过的正文并允许重试。结果未知时让用户核对回执；只有接收端确认成功，才显示「已提交」。 |
| 群还在，Bot 无法回应 | 停掉测试 Bot 的后台，确认用户仍可从社区详情打开官方排错指南，手工收集版本、发生时间和界面错误。用户也可直接从配方概览进入官方表单。不要要求用户先通过已经离线的 Bot。 |

本次收件验收使用一份标记为「验收」的模拟报告。CLI dry-run 预览前后表内均为零条，未模拟浏览器填写后取消。经公开分享表单提交后，飞书返回成功，维护者在底表复核六个字段，内容一致，追踪编号为 `QA-20261113-A01`。用相同正文再次提交，底表增加第二条记录，两条均已标记为「非产品问题」。此表单允许用户主动再次填写，接口未提供请求幂等键或工单号。Bot 不会自动提交或重试。底表的链接阅读已关闭，只有填写表单对外开放。
