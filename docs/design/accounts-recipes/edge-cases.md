# 开发前逐角色复查

不把「点得通」等同于能公开发布。这里列出会直接改变设计的异常场景、系统责任和用户下一步；与产品、接口和上线验收一起使用。

| 容易漏掉的情况 | 首版决定／失败后怎么办 | 验收观察 |
| --- | --- | --- |
| A 用设备退出，B 马上登录，飞书旧卡仍可点 | 请求、加密票据、草稿、未上传临时文件都按原账号和来源 Bot 绑定；切号暂停，旧卡不借 B 权限继续、用户看不到别人的草稿；同一原账号可恢复未过期操作。 | 两个账号同机，两个人都可能是飞书管理员；用另一位回调、过期 token、断线重启都不能交叉写。 |
| 多个同名的群、Bot、配方、草稿 | 显示所属 Bot/群、作者、版本辅助辨认。ID 选定才操作；群内预选，私聊有歧义只询问一次。不能靠名字或最近接触记录决定私聊收件人。 | 两个来源同名、两份草稿同名、修改「这个」均不误改其他对象。 |
| 取消、超时或 App 退出 | 区分未投递、平台已接收、待选择、待同步、草稿就绪。回执未知先对账，不自动发第二张可能产生第二个结果的卡。取消赢则不产生草稿；完成赢则回到现有私人草稿，可另行删除。 | 同操作 ID 重放并查实际数据库；错误不得显示已公开或已安装。 |
| App 正编辑，聊天也改；旧确认挂着 | 草稿 revision 比对；确认卡展示差异，冲突先取最新。App 暂存未提交输入直至明确处理；发布封印后的旧提案不可改该版本。允许从已发布开新版本草稿。 | 同字段冲突、不相交字段重算、已删除草稿、已发布草稿、重复确认各一例。 |
| ORM、搜索、图片、私聊卡等旁路 | 禁止把受限字段混入公共投影、错误/分析日志、对象名、Markdown 自动加载、私聊隐藏字段、链接；守卫放在真实请求处理处。编写公开简介和 Logo 前说明「凭码配方也公开显示」。受限来源不能通过二次发布变公开。 | 用唯一哨兵直接查无权响应、CDN、飞书消息体和对象桶；至少覆盖非作者、已获旧版、当版。 |
| 技能、模型或权限在目标机不兼容 | 先检查目标设备、schema、Provider、技能/规则支持范围。可选项显示跳过原因，必需项不支持就停止并保留已获取；不静默放宽权限，也不自动执行 setup。时区使用目标设备/群的显式设置，预览下一次执行时间，任务默认暂停直到用户启用。 | Windows/macOS 两种目录语义、机器时区不同、缺 Provider、同一项目目录被多群引用。 |
| 配额、上传或项目总预算已满 | 单版本、每账号历史、临时对象和频率分别预算。预检给出最大项及删除建议，服务器最后裁决。限写仍可查原操作及已装版本；计费告警不能靠免费配额自动解决。 | 等于边界、+1 字节、两人同时发布、同一上传链接重复 finalize、历史 Logo 共用引用未误删。 |
| 用户复制链接或码、撤下后再访问 | 链接固定版本、不含码；对已公开发布点复制一次即可。浏览器拒绝剪贴板则提示手动。普通撤下保留原已获权益，未领不能新兑；强制封禁另行处理。账号库默认最高已获 revision，补领旧版不使库倒退。 | 链接从另一个账号／无账号打开、旧链接与新 Logo、用户已获得时输入第二枚码不消耗。 |
| 线上有历史授权，作者要求清理 | 历史条目不能因换 Logo、达到额度或删一张图片直接丢掉。用户可以删除未发布草稿；明确告知是否还在其他设备编辑；撤下已发布走独立状态。初期无全职审核，至少有举报接收、停发/封禁、审计与处理责任人。 | 强制封禁不向任何人继续分发；不承诺远程清除已经落到他人设备的文件。 |
| 账号删除、托管项目暂停、远程不可达 | 退出登录不等于删账号。公测前必须确认账户删除入口、权利/署名处置、服务保留期、告警、恢复演练。云不可用时，已有群和手动配对依然工作；查看缓存标注时间，兑换/云发布不能声称成功。 | 从备份恢复版本、资产与权益；RLS、Storage 两层读写恢复；测试服永不指向正式 Bot 和项目。 |

产品没有必要给所有情况各做一个弹窗。优先留在原任务：能重试的重试同一操作，不能决定时才要求用户选择；需要重新审核的场景给出发生变化的具体字段。

### 小团队也能执行的默认处置

- **误发与举报。** 作者发现发错，去该版本的发布记录按「撤下」，二次确认说明已获取者仍能重装。公开详情和失效链接提供「反馈问题」并带版本 ID，不把分享码、私有正文或截图自动附上。运营者可单独暂停某个版本的新分发或强制封禁；若某版疑似泄露密钥，优先暂停分发并提示作者轮换已泄露凭据。记录理由和处理人，反馈人能得到处理编号。无人维护时先限量邀请试用，不开全量公开发布。
- **删除与恢复的建议默认。** 草稿删除要求明确确认，随后从本人各端消失，未提交旧卡失效。账号删除在近期重新认证后列出私人草稿、自己持有的资格与已发布作品：停止新领取、清理私人数据及账号会话；对受普通撤下规则保护的已获版本保留履约所需的版本、最小授权记录和不可逆的去标识作者引用，移除公开个人资料；涉及隐私、侵权或强制删除诉求单独进入平台处置，不承诺保留被封禁正文。退出登录不执行上述操作。备份恢复先重放删除记录，不能把已删账号或停用码重新启用。公测前须由负责人成文确认数据留存窗口、删除范围和反馈渠道。
- **发布并不需要等模型。** 本机生成安全候选后，卡片选择与 App 表单能完成全程。模型异常、超时、没有可用 Provider 时，给同一份草稿的表单或卡片，保留已选项，允许继续。不要偷偷切换到另一个收费模型，也不要为重试复制一份草稿。
