# 下载分发接入与验收

2026-11-04。范围是早期国内优先的软件分发，海外仅 Linux；不改变产品版本，不替代新版本的最终发布验收。

## 选型与成本

- 国内：现有 COS 保存文件，腾讯境内 CDN 负责下载；购买一次性 100GB / 12 个月有效期流量包，20 元，自动续费关闭。这是有效期内累计 100GB，不是每月 100GB。
- 不叠加购买 68 元 COS 直出套餐。现有 COS 直出包用于过渡，CDN 回源、存储、请求另计。
- 海外：R2 Standard 仅保存 Linux 两架构包和必要脚本/清单，Workers Free 只读入口绑定私有桶。没有迁移现有 DNS 托管，没有启用付费 Workers 套餐。
- R2 免费额度内可为 0 费用，超额存储/操作付费，出站流量免费。Workers Free 每日请求额度是另一项容量限制，不是无限服务承诺。

依据：[腾讯 CDN 流量包](https://cloud.tencent.com/document/product/228/60462)、[COS 计费](https://cloud.tencent.com/document/product/436/53863)、[R2 pricing](https://developers.cloudflare.com/r2/pricing/)、[Workers limits](https://developers.cloudflare.com/workers/platform/limits/)。实际账单随用量、缓存命中和地区变化。

## 云端配置

- 下载域名接入境内大文件 CDN，HTTPS 回源 COS。原 DNS 目标保存在本机证据中以便回退。
- COS 给 CDN 的读取授权限定 `bot/*`，无写入权限。
- 版本化文件遵循源站长缓存，保留 Mac `stable/` 下的版本化 ZIP/DMG/feed 缓存。
- 精确排除 Mac `stable/manifest.json`、Windows 两架构 `stable/*/update.json`、Linux `stable/manifest.json` 与 install/uninstall 脚本；错误响应不缓存，关闭启发式缓存。
- 分片回源开启。Windows 差分客户端兼容由另外的任务处理；本片验证 HTTP Range 和缓存。
- R2 Worker 只允许 Linux 确定路径和 GET/HEAD，支持单段 Range/If-Range；可变对象及错误 `no-store`。不代理任意网址，不开放目录列表或写入。

## 国内真实下载

本机联通线路，经物理网卡直连，绕过系统 HTTP 代理并固定 CDN 地址，保留正常 TLS 域名和证书验证。三份均为完整 0.9.1 包，与本机原始发布产物计算完整 SHA-512 对照。

| 包 | 字节数 | 总用时 | 平均速度 | 首字节 | 校验 |
|---|---:|---:|---:|---:|---|
| Windows x64 EXE | 132,133,562 | 23.42 秒 | 5.64 MB/s | 0.38 秒 | 一致 |
| Linux x64 tar.gz | 64,023,136 | 11.64 秒 | 5.50 MB/s | 0.33 秒 | 一致 |
| Mac arm64 ZIP | 142,309,823 | 23.94 秒 | 5.94 MB/s | 0.30 秒 | 一致 |

这些是单线路、单轮实测，不是全国速度保证。首次整包是 Cache Miss；后续 Windows/Mac Range 返回 206、正确范围和 Cache Hit。六个可变对象用不加随机参数、不发送强制绕缓存头的普通 GET 对照源站，字节全部一致且返回 no-cache/Cache Miss。

## 自动选源与验证边界

安装命令先并发获取完整脚本；清单也并发探测并验证签名。两边就绪优先国内，镜像先就绪最多给国内 300ms 优先窗口。慢速有进展允许持续下载；无进展失败后备用源从零安全重下，不宣称跨源断点续传。

本地真实 HTTP 故障注入中，国内黑洞时引导约 0.8 秒取得镜像脚本。签名拒绝、半包、错误尺寸/哈希、败方取消、外层 SIGTERM 清理及旧镜像抢先返回等均有回归。打包回归检查实际 tar 内保留镜像配置。发布回归覆盖 CDN 陈旧缓存、精确计划、R2 条件写入竞态和失败后撤销官网交接状态。

现有 0.9.1 包与正式安装脚本保持原发布字节。双源安装器/升级器和新的官网复制命令需要经过本次代码验收、合入和后续正式发布才会覆盖用户安装流程；只建好 R2 桶不代表旧客户端已经支持双源。

本报告记录国内接入基线。海外完整下载与隔离安装的单独验收结果见本片 PR 描述及本机原始回执；服务注册/运行态若跳过须单独标明，不用网络测试代替完整系统验收。
