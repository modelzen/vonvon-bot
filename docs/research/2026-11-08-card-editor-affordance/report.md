## 本项目采用的方案（设计取舍，并非竞品事实）

主要参考 Shopify 的预览内编辑，结合 Notion 的拖动把手。进入编辑器先选中一个实际存在的组件，显示紧贴内容的细边界，以及拖动、设置、隐藏三个小控件。点正文或设置控件进入详情，拖把手或内容移动到合法槽位。鼠标移到其他组件后，操作控件跟随该组件；没有整段蓝字、手指插图或单独引导气泡。首次选中是为解决“用户还没有悬停，就不知道这里能操作”，不是自动打开详情。

不修改飞书引用、回复正文和其他不可配置内容。自动轮播继续运行；仅鼠标进入卡片本身、键盘在卡片中操作、拖动或打开设置时暂停。

## 同轮上下文设置

颜色分档与出现条件独立。默认 70% 起黄色、85% 起橙色、95% 起红色；低于第一档为灰色。用自然句式展示各档起点，替代“用量较高时标红”。出现条件可选择不限用量，或达到指定用量才出现；例如 80% 是包含边界的下限。显示阶段独立控制全程显示或仅执行中。

进度条与文字共用上、下信息行及左右半行槽位；切换形态保留位置。仅 UI 草稿和原生 Card JSON 的本地预览，后续仍需接入 daemon、CLI 和正式飞书验收。

## owner 后续修正

owner 否决默认选中、常驻组件框和三个图标组成的操作框，要求恢复原先的悬停交互。本报告中“初次选中加工具栏”的方案没有通过验收，已从 UI 撤回。当前平时不画组件边框，悬停或键盘聚焦时出现细边框和隐藏按钮；仍直接点击内容设置、拖动内容换位。上下文颜色分档、出现条件、半行进度条保留。
