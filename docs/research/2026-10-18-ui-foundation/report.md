# 网页端打底审查清单（2026-10-18）

这是 `docs/v1-plan.md` 第 1 节"界面分三段调"第一段（打底）的只读审查，源码是 `main` 的 `2e2c161`。做法：在 JP-VPS 上起一个隔离的临时 daemon（`HOME`、`VONVON_HOME` 都在 `mktemp -d` 的目录里，没碰验收 daemon），写进三个假 Bot、五个群和几条会话记录，用 Playwright 无头 Chromium 在 1280 和 390 两种宽度下截了 204 个场景；Bot 真正运行时的页面用拦截 WebSocket 的办法模拟（`m` 开头的图），空安装另起一个 daemon（`e` 开头），极端数据（无空格长名、空群名、125 个群、12 个待绑定群）再截一轮（`bx` 开头）。四个审查者（另一个模型）各看一个角度：视觉和组件（`emil-design-eng`）、极端数据和窄屏（`break-ui`）、交互和流程（`apple-design` 的反馈、寻路和简洁三条）、样式体系和叫法（`pick-ui-library` 加静态统计）。本文由 Fable 合成：每条事实抽查了源码或截图，不对的没收，核对记录在末尾。

截图和索引留在 JP-VPS 本机，不进仓库。没截到的：Bot 真正连着飞书时的页面（只有模拟）；注册 Bot 扫码后的各阶段、一键开权限、二维码过期；刷新凭据对话框；Codex 登录的设备码页；本机工具安装、更新、卸载的确认框和进度；删除 Bot、启停 Bot、重启和停止 daemon 之后的页面；建群和绑定成功后的页面和欢迎卡片；群内设置真的保存、解除绑定确认框；"内容暂不可用"；桌面版专有的托盘、窗口、登录项；真实 macOS 字体和 emoji 下的效果（VPS 上 emoji 是方框、拉丁字母比中文粗，是字体回落，不算发现，到 Mac 上看一次）。

行数是粗估，不含测试。"碰 s28"指改到群详情页（`App.tsx` 的 membership 段、`management/ProjectPanel.tsx`、`management/ConversationPanel.tsx`、`settings/SettingsPanel.tsx` 的群作用域）或要在 s28 之后改的页面。"已记下"指 v1-plan 第 1 节已经记着的问题。

### 决定

- D1（F34）会话方式。(a) 留在主界面（到 s25 是三张卡），更多设置只放文件夹和免 @；(b) 给默认值多会话，收进更多设置，收起时摘要行写出当前值，改 product.md 3.4 的"不预选"只管飞书里的设置卡，命令行照旧必须带。推荐 (b)：主界面只剩群名和后端，默认值能看见，不用展开。
- D2（F36）路径。(a) 建好后在"已建好"提示里显示目录（daemon 已经回了，5 行）；(b) 建群前就显示"会建在 …/<群名>"，daemon 设置视图加一个预览字段（约 40 行，小的行为改动）。推荐先做 (a)，(b) 要 owner 点头。
- D3（F38）从群聊页建群时选 Bot。推荐：只有一个启用的 Bot 时不问；有几个时表单第一行加"用哪个 Bot"。owner 的方向只说了问群名和后端，所以要确认。
- D4（F44）待绑定群。(a) 每个 Bot 合成一条提示，Bot 页加"待设置"分组，浮层只报新来的（推荐）；(b) 保留逐条，最多显示 3 条加"还有 N 个"。
- D5（F45）群很多时。(a) 推迟，只加群数（推荐）；(b) 每群一行、超过 8 个群出筛选框；(c) 保留每群一张卡，只加筛选框。
- D6（F08）手机宽度。推荐不支持，网页最小宽度和桌面的 780 对齐。
- D7（F05）纯删除的 PR 能不能超过 1,500 行。推荐允许：按文件一片，用脚本和前后截图核，审查者不逐行读。不允许就按本文拆成三片，`pages.css` 自己还要再拆两次。
- D8 叫法表的待定项：后端 / 执行工具；后台服务 / daemon；Profile 的中文。
- D9（F29）目录选择器要不要换成系统原生的（桌面端加能力，网页端保留现在的）。是新能力，推荐留到最后一轮或不做；打底只把现在的做像样。
- D10（F48）路径：详情页折行、列表和搜索里中间省略（推荐），还是所有地方都折行。
