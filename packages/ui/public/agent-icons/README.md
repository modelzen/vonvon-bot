# Tool icon sources

- `codex-light.png` and `codex-dark.png` are 128 px copies of the official
  `icon-codex-light.png` and `icon-codex-dark-color.png` resources shipped in
  the OpenAI-signed Codex desktop bundle (`TeamIdentifier=2DC432GLL2`). The
  source artwork was only resized; its geometry and colors were not changed.
- `claude-code.svg` was downloaded without modification from Anthropic's
  official Claude site: <https://claude.ai/favicon.svg>.
- `feishu.png` was downloaded without modification from the icon published by
  [Feishu's official website](https://www.feishu.cn/):
  <https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/84a9f036fe2b44f99b899fff4beeb963~tplv-jbbdkfciu3-image:0:0.image>.
- `typesafe.png` is a 64 px copy of the favicon published by
  [TypeSafe AI's official website](https://typesafe.ai):
  <https://framerusercontent.com/images/aNFzSFxM4fjICmnibw7npfZjcQ.png>. The
  source artwork was only resized; its geometry and colors were not changed.

These marks identify the corresponding products in the local-environment,
project-grouping and usage interfaces.
