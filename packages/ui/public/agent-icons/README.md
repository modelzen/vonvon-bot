# Tool icons

These general-purpose symbols distinguish terminal tools, code assistants, messaging, and decision services. Product names in the interface identify the integrations.

## Usage tab icons

- `codex-light.png` is the resized Codex icon from OpenAI's signed Codex desktop bundle.
- `claude-code.svg` is the original icon from [Claude's website](https://claude.ai/favicon.svg).
- `typesafe.png` is the resized favicon from [TypeSafe AI's website](https://typesafe.ai), shown for Jev.

These three assets match the ones distributed with Vonvon Bot 0.10.1.
